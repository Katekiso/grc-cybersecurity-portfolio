# Banking Access Control Risk Assessment

## 1. Project Overview

This project evaluates access control risks
within a simulated commercial banking environment.

## 2. Organization

ABC Commercial Bank (Fictional)

## 3. Assessment Objective

To identify weaknesses in employee access
management and recommend security controls
to reduce unauthorized access to sensitive
customer and financial information.

## 4. Scope

- Employee user accounts
- Access privileges
- Access approval procedures
- Periodic access reviews
- Employee termination procedures

## 5. Assessment Approach

The assessment will use risk management
principles and relevant NIST Cybersecurity
Framework 2.0 guidance.

## 6. Disclaimer

This is an educational simulation using
fictional organizational information.
