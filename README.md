# Cybersecurity GRC Portfolio

## About This Portfolio

Welcome to my Cybersecurity Governance, Risk, and Compliance (GRC) portfolio.

I am a graduate student pursuing an MS in Cybersecurity at Yeshiva University, with a professional background in banking, financial operations, risk management, and regulatory compliance.

This portfolio showcases practical cybersecurity projects and simulated labs focused on identifying security risks, evaluating controls, assessing compliance, and developing risk mitigation recommendations.

- NIST Cybersecurity Framework (CSF) 2.0

- Operational Technology (OT/ICS) Security
